VU research demonstration

This demonstrator presents part of the VU research on knowledge representation for fault diagnosis. The wider project includes additional research and results not yet shown on this site.

How the work relates to the factory

The Fischertechnik factory provides a concrete system to describe and explore. The ontology defines concepts and relationships for diagnostic knowledge; the knowledge graph connects information about the demonstrator using those concepts. For the factory demonstrator, the original ZORRO ontology has been extended with concepts and relationships based on the factory and its parts. This demonstrator extension builds on the original ontology and provides a more specific description of the equipment. In the ontology viewer, visitors can switch between the original ZORRO ontology and the demonstrator extension. The query tools let visitors ask questions of the graph.

Use the menu above to explore the ontology and graph, run example SPARQL queries or build your own query.

Explore the tabs

The ontology defines the vocabulary, the knowledge graph contains connected information expressed using that vocabulary, and the query tools retrieve information from the graph.

Ontology

Explore the concepts and relationships used to describe diagnostic knowledge. Compare the original ZORRO ontology with the demonstrator extension, which adds concepts and relationships for the factory and its parts. This helps explain how the information in the graph is organised.

Knowledge graph

Browse the connected resources representing the demonstrator and its knowledge. Search or filter the graph, select a resource and inspect its properties and relationships. This is useful for seeing how components and other information connect.

SPARQL queries

Run example questions against the knowledge graph and inspect their results. Examples provide a starting point for exploring factory information; you can also edit the SPARQL to ask your own questions. This is useful when you want to retrieve a specific set of connected facts rather than browse the graph visually.

Open SPARQL queries

Query builder

Build a query by selecting types, relationships and values from the graph. The builder creates SPARQL that you can run or edit, making it useful for exploring questions without writing the entire query yourself. It uses the same graph as the SPARQL examples.
