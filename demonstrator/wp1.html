WORK PACKAGE 1

Monitoring systems

Develop robust monitoring at hardware, software, component and system level, including monitoring of the monitoring system itself.

More about the work packages on the ZORRO project website

Work package information

Leader: Dr. Berend Jan van der Zwaag

Goal

Design and develop robust system-level monitoring as an integral part of cyber-physical systems, covering hardware, software and algorithms; components and their interactions; monitoring of the monitoring system itself; and embedded intelligence for faster diagnostics.
